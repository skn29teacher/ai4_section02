```
cot 와 langchain react를 이용해서
사용자의 질문에서 의도를 분석해서 react를 호출(도구 호출하는 예제를 만들어봅시다)
```

예)
오늘 000지역을 여행하려고 하는데.. 숙소 정보와 날씨 정보를 이용해서
최적의 여행 코스를 알려줘

숙소 --> 숙소관련 Db에서 데이터를 찾아서 LLM 제공(api가 있다면 적극 적으로 이용)
날씨 --> 날씨관련 정보를 찾아서 LLM제공(api가 있다면 적극 적으로 이용)


개발팁: llm을 이용하거나 키워드를 추출해서 사용자의 질문중에 함수호출(acting)이 필요하면  해당 함수를 호출하고 결과를 llm전달 해서 답변을 생성
